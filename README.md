### 🧭 About Me

I'm a full-stack and cross-platform developer who enjoys building software across the whole stack — from embedded systems and mobile apps to web platforms and databases. I like picking the right tool for the job rather than sticking to one ecosystem, which is why my work spans everything from C# and .NET to React, Next.js, Python, and Swift.

- 💻 I build web apps, mobile apps, APIs, and occasionally hardware-integrated projects
- 🧩 Comfortable working across the stack: frontend, backend, databases, and DevOps basics
- 📚 Always exploring new languages, frameworks, and tools to solve problems better
- 🤝 Open to collaborating on interesting projects, freelance work, or open source
